# IndoWings

Next-generation autonomous defense UAVs, tactical surveillance drones, and aerial reconnaissance platforms.

## Overview
IndoWings develops mission-grade unmanned aerial systems designed for high-altitude endurance, tactical intelligence, and extreme operational environments.

### Product Fleet
- **Cyberone Max**: Heavy-lift multi-payload logistics and high-altitude surveillance UAV (up to 23,000 ft AMSL).
- **Cyberone Pro**: Tactical day/night reconnaissance UAV with edge-AI tracking and real-time secured datalinks.
- **Cyberone Lite**: Rapid-deployment tactical scout UAV with swappable solid-state battery and RTK positioning.
- **Cyberone Trainer Drone**: Master-slave dual-pilot remote training platform.

## Tech Stack
- **Frontend**: React, Vite
- **Styling**: Vanilla CSS
- **Motion**: Framer Motion, GSAP (ScrollTrigger)
- **Icons**: Lucide React

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
